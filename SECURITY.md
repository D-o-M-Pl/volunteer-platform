# Security Policy

## Supported version

Only the latest commit on the `main` branch is supported.

## Reporting a vulnerability

Do not open a public issue and do not include credentials, tokens, personal data,
or exploitation details in public discussions.

Use GitHub's **Report a vulnerability** option in the repository Security tab to
submit a private vulnerability report. Include affected versions, reproduction
steps, impact, and a proposed mitigation when possible.

Please allow the maintainer reasonable time to investigate before disclosure.
